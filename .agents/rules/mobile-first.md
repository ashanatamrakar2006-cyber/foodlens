# Rule: Mobile-First UI
**When to apply:** When designing or implementing user interfaces.

- **Strategy:** Mobile-first implementation is mandatory. Desktop is an extension of the mobile information architecture, not a separate layout.
- **Validation:** Must validate correctly at 320px+. No horizontal overflow.
- **Interaction:** Touch-friendly controls (min 44x44). No essential hover-only interactions.
- **Testing:** Test important screens at both mobile and desktop widths.
