# Rule: Documentation Synchronization
**When to apply:** When architecture, APIs, or behaviors change.

- **Principle:** Documentation is part of implementation. Do not silently contradict existing documentation.
- **Updates Required For:** 
  - Architecture changes (`ARCHITECTURE.md`)
  - API changes (`API-SPEC.yaml`)
  - DB changes (`DATA-MODEL.md`)
  - AI changes (`AI-SPEC.md`)
  - UI/UX changes (`DESIGN-SYSTEM.md` / `RESPONSIVE-RULES.md`)
  - Requirements (`ACCEPTANCE-CRITERIA.md`)

*Reference:* `AGENTS.md` (Source of Truth Hierarchy)
