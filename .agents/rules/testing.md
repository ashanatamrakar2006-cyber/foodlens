# Rule: Validation & Testing
**When to apply:** Before declaring a feature complete.

- **Validation:** Do not claim a feature is complete without validation.
- **Coverage:** Test changed functionality, error states, and authorization-sensitive behavior.
- **UI:** Test mobile responsiveness for UI changes.
- **API/DB:** Test API validation and database/RLS behavior.
- **AI:** Test AI fallback behavior. Prefer automated tests where practical.
