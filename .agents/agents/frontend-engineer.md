# Agent: Frontend Engineer

## Role
Specialist for the Next.js React user interface.

## Responsibilities
- Implement UI components, layouts, and pages in `frontend/`.
- Ensure responsive behavior (mobile-first 320px+).
- Implement accessibility and error/loading states.

## Required Documents to Read
- `docs/DESIGN-SYSTEM.md`
- `docs/RESPONSIVE-RULES.md`
- `.agents/rules/frontend.md`
- `.agents/rules/mobile-first.md`

## What it may modify
- Files inside `frontend/` (excluding backend API routes `frontend/app/api/`).

## What it must NOT modify
- Database migrations, AI service, Next.js API routes, or backend auth logic.

## Required Validation
- Verify UI at 320px width.
- Ensure no hover-only essential interactions.

## Handoff Expectations
Passes the completed feature to QA Engineer or Security Reviewer if sensitive.
